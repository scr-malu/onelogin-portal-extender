## OneLogin Portal Extender

OneLogin Portal Extender は、OneLoginのポータル画面（*.onelogin.com/portal）をもっと便利に使うための拡張機能です。

主な機能:

- **初期表示タブの切り替え** — ポータルを開いた際に最初に表示されるタブを「利用頻度の高いもの」から「Company Tab」に自動で切り替えます。タブ名を自動検出するため、個人タブの有無などの事前設定は不要です。
- **チラつき防止** — タブの切り替えが完了するまでページを一瞬隠すことで、「利用頻度の高いもの」タブが一瞬見えてから切り替わるチラつきを抑えます。
- **アプリのピン留め** — ポータル上のアプリにマウスを乗せると表示される ★ ボタンでアプリをピン留めでき、ピン留めしたアプリはポータル最上部のバーからワンクリックで起動できます。
- **対象ドメインの限定** — 複数の OneLogin テナントを利用している場合に、特定のテナント（サブドメイン）だけで動作させることができます。

## 使い方

拡張機能をインストールするだけで、OneLoginのポータル画面を開いた際に自動的に Company Tab が表示されます。「利用頻度の高いもの」「個人」タブ以外で最初に見つかったタブが自動で選択されるため、旧バージョンで必要だった「個人タブあり/なし」の設定は不要になりました。

なお、Company Tab のうちどのタブが最初に表示されるかは OneLogin のプロフィールページ > プロフィール > 会社タブの初期値 で各自がご設定頂く必要があります。

## オプションの設定

拡張機能のアイコンを右クリックして「オプション」を開くと、以下の設定ができます。

- **初期表示タブ** — 「会社タブを自動検出」（デフォルト・推奨）のほか、表示したいタブ名を直接指定したり、切り替え自体を無効にすることもできます。一度ポータル画面を開くと、実際のタブ名がプルダウンの選択肢として表示されます。なお、会社タブの中に複数のタブがある場合にどのタブが最初に表示されるかは、OneLogin のプロフィールページ > プロフィール > 会社タブの初期値 でご設定ください（本拡張機能では変更できません）。
- **対象ドメイン** — 動作させたいテナントのドメイン（例: `example.onelogin.com`、サブドメインのみでも可）を1行に1つ入力します。空欄の場合はすべての *.onelogin.com で動作します。
- **ピン留めアプリ** — ポータル上で ★ ボタンからピン留めしたアプリの一覧確認と削除ができます。

## 開発者向け

Chrome Web Store 提出用の zip は以下のコマンドで生成できます（`dist/` に出力されます）。

```sh
bash scripts/build.sh
```

GitHub Actions でも自動ビルドされます。`v*` 形式のタグ（例: `v1.1.0`）を push すると、zip が添付された GitHub Release が自動作成されます。
